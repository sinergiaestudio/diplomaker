# Hoja de ruta

## Completado en 2.1

- editor visual por capas;
- fondos propios;
- textos fijos y variables;
- imágenes, logos y firmas gráficas;
- bloques dinámicos de firmantes;

## Diplomaker 2.2 — Identidad, experiencia y escritorio

### Implementado en alpha.1

- identidad visual oficial;
- tema claro predeterminado;
- tema oscuro y automático;
- autoría integrada;
- portada y navegación móvil renovadas;
- biblioteca de proyectos;
- respaldo y restauración de toda la biblioteca;
- solicitud de almacenamiento persistente;
- instalación PWA visible;
- gestión explícita de actualizaciones;
- base Tauri para Windows;
- persistencia en archivos locales;
- instaladores NSIS y MSI;
- automatización de paquetes web y Releases.

### Antes de release candidate

- probar el recorrido funcional completo en el tema claro y oscuro;
- verificar actualización 2.1 → 2.2 sin pérdida de proyectos;
- validar instaladores en Windows 10 y Windows 11;
- comprobar apertura mediante asociación `.diplomaker`;
- comprobar desinstalación sin borrar la carpeta Documentos;
- revisar la biblioteca con proyectos grandes y recursos gráficos pesados;
- incorporar capturas finales al repositorio;
- publicar una vista previa temporal para validación del usuario;
- resolver advertencias de accesibilidad y contraste que surjan de las pruebas.

### Antes de versión estable

- release candidate firmado mediante tag;
- manual de usuario 2.2 actualizado;
- SHA-256 de todos los paquetes;
- notas de versión completas;
- decisión sobre certificado de firma de código;
- validación final de GitHub Pages, PWA y GitHub Release;
- actualización del perfil público de Marcelo Gómez.
