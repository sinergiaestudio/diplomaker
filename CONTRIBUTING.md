# Contribuir

1. Cree un fork y una rama descriptiva.
2. Ejecute `npm run check`.
3. No incluya datos personales, firmas reales, logotipos de terceros ni plantillas con marcas no autorizadas.
4. Mantenga el funcionamiento sin conexión y evite dependencias remotas.
5. Abra un pull request con las pruebas realizadas.
